# Quant-Practice
Quantitative research practice in Python: probability, statistics, algorithms, simulation, and financial modeling.

## Problem Set

[Launch instructions, sourced questions, and official firm guides](problem_set/README.md)
for a timed, ten-question interview practice webpage. The problem types adapt
published Jane Street and Susquehanna examples; the guide section also links to
Citadel, Two Sigma, Optiver, and IMC. Run locally with
`python3 -m streamlit run problem_set/app.py` after installing `requirements.txt`.
