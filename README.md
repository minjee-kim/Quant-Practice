# Quant-Practice
Quantitative research practice in Python: probability, statistics, algorithms, simulation, and financial modeling.

## Problem Set

[Launch instructions and sourced question templates](problem_set/README.md) for a timed,
ten-question interview practice webpage. The problem types are adapted from Jane
Street's public quantitative interview-preparation guide. Run locally with
`python3 -m streamlit run problem_set/app.py` after installing `requirements.txt`.
