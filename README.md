# Quant Practice

Practice probability and statistics for quant interviews. The timed app has
theory questions, distribution drills, and mental math, with worked answers
and a results breakdown. Questions adapted from published firm guides are
labeled as such; the other exercises are original practice.

**[Open the practice app](https://quant-practice.streamlit.app/)**

## Repository folders

| Folder | Contents |
| --- | --- |
| [`basics/`](basics/) | Python basics and short exercises. |
| [`probability/`](probability/) | Dice maximum: simulation and theoretical calculation. |
| [`statistics/`](statistics/) | Sum of two uniforms: density and simulation. |
| [`problem_set/`](problem_set/) | Streamlit app, question bank, scoring code, and [setup notes](problem_set/README.md). |
